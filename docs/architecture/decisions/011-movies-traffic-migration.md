# 011. Случайное переключение трафика Movies

Дата: 2026-11-08. Статус: принято. Основание: явный выбор пользователя в согласованном плане задания 2.

## Контекст и ограничения

Каждый запрос `/api/movies` и вложенных путей независимо выбирает movies при `rand.IntN(100) < MOVIES_MIGRATION_PERCENT`. Health всегда идёт в movies. При `GRADUAL_MIGRATION=false` весь каталог идёт в movies; откат задаётся `true/0`. Конфигурация применяется после пересоздания proxy.

## Альтернативы и выбор

Стабильное закрепление пользователей и точная доля короткой серии не требуются. Альтернатива — закрепление маршрута по пользователю — потребовала бы идентификации, которой нет в MVP. Ошибка выбранного upstream возвращается как 502/504 без fallback: повтор POST мог бы создать повторную запись после потери ответа.

## Последствия и риски

Общая PostgreSQL позволяет читать созданный фильм через другой upstream. При разделении данных стратегию нужно пересмотреть. Автоматическое восстановление доступности не гарантируется; оператор меняет флаг для отката. Это согласованный компромисс для учебного перехода; вероятность отказов не измерена.
